# Architecture

- **Next.js 16 (App Router) + TypeScript + Tailwind 4.** Pages are server-rendered (`force-dynamic`) from the DB.
- **DB:** embedded Postgres (PGlite, `data/pg`, or `DB_DIR`) with `pg_trgm`. SQL migrations in `migrations/` (001 init, 002 auth, 003 employer, 004 profiles, 005 alerts/outbox, 006 RLS + AI usage, 007 analytics, 008 account security), applied by `src/lib/db.ts#migrate`. Set `DATABASE_URL` to use real Postgres via `pg` (`pgDb` adapter behind the `Db` interface in `src/lib/db.ts`; pooled, migrations serialised with an advisory lock); unset, the app uses embedded PGlite (single-process, dev/tests only). The whole unit suite passes on both: `TEST_DATABASE_URL=postgres://… npm test` (creates/drops a throwaway database per test) and the browser suite via `E2E_DATABASE_URL`. Migrations expect a role that may `CREATE ROLE`/`GRANT` (needed once for `app_user`); in production the app's DB user is the one that runs migrations and then `SET ROLE app_user` inside `withUser()`.
- **Search** (`src/lib/jobs.ts`): `websearch_to_tsquery('simple')` over a weighted generated `tsvector`; on zero hits, trigram similarity on title/company (typo tolerance). `simple` config keeps Arabic searchable (no stemming).
- **Auth** (`src/lib/auth.ts`): scrypt password hashes, DB-backed sessions (only the SHA-256 of the token is stored), httpOnly cookie, 5-failure/15-min account lockout, identical error for unknown user vs wrong password. Email verification (needed to post jobs / create alerts; unverified users get no alert mail) and password reset use single-use hashed tokens (`src/lib/account.ts`); reset logs out every device; verify/reset links are POST-confirmed so mail scanners can't burn them. Per-IP/per-email limits in `src/lib/ratelimit.ts`. `/account/export.json` and `/account/delete` cover data portability/erasure. Roles: candidate / employer / admin. Admin cannot be self-registered (`npm run make-admin -- email`). Guards: `requireRole()` in `src/lib/session.ts`; business rules (ownership, admin-only) are also enforced in `lib/employer.ts` / `lib/admin.ts`, not just in pages.
- **RLS** (`migrations/006`, `src/lib/rls.ts`): `profiles` and `saved_searches` have forced row-level security for role `app_user`; `withUser()` switches role and sets `app.user_id` per transaction. Only those two tables are covered, and only code paths that use `withUser()` are protected — the default connection is a superuser and bypasses RLS.
- **i18n/SEO:** English unprefixed, Arabic under `/ar` (`src/proxy.ts` — Next 16 name for middleware — rewrites and sets `x-locale`). `alternatesFor()` emits canonical + hreflang (`en`, `ar`, `x-default`); sitemap lists both locales with alternates. Landing pages `/country|city|company/[slug]` are `noindex` and excluded from the sitemap below 3 active jobs. `JobPosting` JSON-LD only for active, unexpired jobs with a description.
- **Employer / admin:** `/employer` (post, close own jobs), `/admin` (stats, sources, ingestion runs, users/roles, remove job, top pages).
- **Candidates:** `/account` profile, `/account/cv` printable CV (any script), `/account/cv.pdf` server PDF (Latin text only; returns 422 otherwise), `/account/alerts` saved searches.
- **Alerts/email:** `runAlerts` enqueues digests into `email_outbox`; `flushOutbox` sends via an `EmailTransport` (currently console only) with 3 attempts. Run with `npm run alerts` on a schedule. Unsubscribe is a POST confirmation page.
- **AI** (`src/lib/ai.ts`): provider interface; off unless `AI_PROVIDER` is set (`mock`, or `anthropic` with `ANTHROPIC_API_KEY` + `AI_MODEL`); 10 uses/user/day. Backend only — no UI yet.
- **Consent/analytics:** opt-in consent cookie; Global Privacy Control treated as reject; AdSense script loads only with consent + `ADSENSE_CLIENT`; first-party analytics stores path, locale, referrer host only, and the server re-checks consent.
- **Ingestion:** see `docs/job-sources.md`.

## Commands
`npm run migrate | seed | ingest | alerts | make-admin | test | e2e | typecheck | lint | build`
E2E locally: `npm run build && PW_CHROMIUM_PATH=<chrome> npm run e2e` (CI installs Playwright's Chromium).
Env: `DATABASE_URL`, `DB_POOL_MAX`, `EMAIL_TRANSPORT=file` + `EMAIL_FILE` (dev), `SITE_URL` (default https://today-jobs.com — domain not purchased/verified), `DB_DIR`, `ADSENSE_CLIENT`, `AI_PROVIDER`, `ANTHROPIC_API_KEY`, `AI_MODEL`.
